# GitHub-ready publishing

BeliefWeave is packaged as a complete repository-ready source tree. No public repository URL is invented in this release.

## What is ready
- source package and tests
- benchmark and dataset tooling
- GitHub Actions workflows
- pull-request template
- issue templates
- CITATION metadata
- license and contribution guide
- static project site

## Publish
Create an empty repository in your GitHub account, then push the contents of `beliefweave-github-ready.zip`.
